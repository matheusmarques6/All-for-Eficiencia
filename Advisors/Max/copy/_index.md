# O esqueleto de 8 campos

Subject Line → Preview Text → Headline → Subheadline → First CTA → Body Copy →
Bridge Section → Product Section. "the skeleton that I'd say 80% of emails
followed to some extent" (L5731). Aparece idêntico no prompt de IA
([[prompt-de-copy]]) e no formato de entrega ([[email-architect]]).
