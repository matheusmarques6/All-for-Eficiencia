# O que tem aqui

O padrão de EXECUÇÃO da Convertfy: como uma peça nossa fica pronta. É a
metade que faltava na base — `Advisors/Max` ensina o que fazer e por quê
(doutrina de curso, com citação verbatim); aqui fica o como, com a peça
à vista e a decisão explicada ao lado dela.

A separação é proposital. Doutrina responde "a hero é a seção mais
importante"; execução responde "esta hero, com este espaçamento, por
esta razão". Quem gera uma peça precisa das duas, e só a primeira
existia.

# Pastas

- `direcao-de-arte/` — como uma imagem nossa deve ser: luz, composição,
  enquadramento, o que nunca aparece. Serve ao prompt de imagem.
- `pecas/` — peças reais com o porquê de cada decisão: popup, e-mail,
  bloco. Uma peça por nota, do jeito que foi para o ar.
