# Os números da doutrina, e onde eles brigam entre si

| Medida | Valor | Cuidado |
|---|---|---|
| Conversão do form | 6-12%, mínimo 6% | o corpus dá quatro versões diferentes: 6-12%, 10%+, 20%+, e "3 a 5% é onde a maioria para" |
| Time delay | 4-12s | três faixas distintas na fonte; só o piso de 4s é comum às três |
| Cobertura de tela | ≥ 75% | consistente |
| Copy | < 10 palavras | consistente |
| Dimensão mobile | 750x500 | |
| Dimensão desktop | 1000x600 | |
| Reexibição após fechar | 5 dias | |
| Corte de formato da oferta | AOV $100 | |

Treze conflitos registrados neste módulo. Os que mais mudam uma resposta: a contagem de tipos de form (o slide diz 5, o material nomeia 4 — **nunca afirme cinco**), a faixa de time delay, o benchmark de conversão, e se o botão X é opcional ou obrigatório.

# O que a doutrina NÃO cobre

Isto é o que a IA deve recusar nomeando a lacuna, em vez de improvisar:

- Nenhum benchmark para post-purchase opt-in, sign-up page ou embed — só para o pop-up.
- Nenhum percentual de desconto padrão. 10%, 15% e 20% são exemplos de demonstração, não recomendação.
- Nenhum tamanho de amostra, duração ou critério de significância para os A/B tests.
- Nenhuma copy para free shipping, free gift ou spin-to-win — todos os exemplos usam 10% off.
- Nada sobre consentimento e compliance.

**É exatamente aqui que o material novo tem mais valor.** Cada lacuna acima é uma nota esperando para ser escrita.

# Referências — peças reais

Pasta: `Referencias/popup/`. Vazia hoje — nenhum pop-up capturado ainda.

**Mas há um item de pop-up na coleção de e-mail.** "Split Welcome Flow By Pop-Up Answer" segmenta a trilha do welcome pela resposta que a pessoa deu no formulário: o pop-up pergunta que problema ela quer resolver, e o flow entrega conteúdo específico para aquela resposta. É o único ponto de toda a coleção da Well Copy que liga captação a flow. Está em [[padroes-estruturais-de-flow]], e o **como** já existe no corpus do Max, em [[segmentacao-vinda-do-form]] — hidden field vira profile property, que vira split no flow.

O que entra aqui: pop-up capturado no mercado, com marca, data, copy literal e o julgamento do que vale roubar. Referência sem julgamento é arquivo morto.
