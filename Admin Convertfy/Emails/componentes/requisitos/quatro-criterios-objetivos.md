# O que é

Existem pelo menos quatro critérios objetivos de comparação de
categoria em que a marca vence de forma defensável — não vantagem vaga
inventada para preencher linha.

# Por que é eliminatório e não preferência

A tabela é a peça inteira dessa variante. Com menos de quatro critérios
a estrutura de tabela não se justifica — três linhas não sustentam o
formato — e sem diferencial real por trás de cada critério, a tabela
expõe vantagem vaga como se fosse fato, o que é o oposto do efeito que
o formato existe para produzir.

Da prosa do inventário, verbatim (`body 5`): *"Menos de quatro
critérios. Com três linhas a tabela não justifica a estrutura."* E:
*"Marca sem diferencial real nos critérios listados. A tabela expõe:
cinco linhas de vantagem vaga soam falsas."*

# Como se resolve
Resolvedor (código, com citação): pesquisa da marca → quatro critérios
objetivos e verificáveis com trecho literal. Sem eles, `false` → elimina.
