# Cobertura

**Nenhuma variante cadastrada.** Das 44 variantes do catálogo, zero
pertencem à seção `cta`. A pasta `variantes/cta/` não existe.

# Consequência

O mesmo buraco de `header`, na seção `cta`. Não é hipotético: duas
estruturas de referência do welcome (`avelmore-inspecao-antecipada`, toque
1, e `avelmore-prova-social-cirurgica`, toque 4) declaram `cta` no próprio
`secoes:` — e o catálogo não tem candidata nenhuma para preencher. Quando
o Montador chega nesse bloco, cai no template global, do mesmo jeito
silencioso de `header`.

Ver [[cta-sem-variante]].

# Chave de decisão

Não se aplica enquanto não houver variante.

# Onde a seção não cobre

Tudo. Em particular, as duas estruturas de welcome que declaram `cta` no
`secoes:` ficam impossíveis de montar por completo com o catálogo atual,
mesmo que todas as outras seções da peça tivessem candidata perfeita — ver
[[estruturas-de-welcome-sem-variantes]].
