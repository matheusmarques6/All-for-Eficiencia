# O que é

Carrega o bloco com uma afirmação central, sem lista, comparação ou prova como estrutura dominante. Move a decisão ao enquadrar como o leitor deve interpretar o que vem antes ou depois.

# Quando usar

Use como ponte ou apoio quando uma única frase precisa orientar a leitura.

# Quando não usar

Não use quando o argumento exige decomposição; use `lista_enumerada`. Para duas alternativas critério a critério, use `comparacao_pareada`.
