# O que é

Torna o percentual, valor ou mecânica o maior elemento da abertura. Move a decisão pela força direta da oferta, sem exigir que o leitor descubra o incentivo depois.

# Quando usar

Use quando a promoção é simples, relevante e suficiente para sustentar o topo.

# Quando não usar

Não use quando a condição precisa ser explicada; use `oferta_condicionada`. Quando o evento é o enquadramento principal, use `campanha_nomeada`.

# O que ele exige

- [[desconto-percentual]]
- [[desconto-automatico-sem-cupom]]

- [[hero-14-lockup-tipografico]] — percentual e reforço formam um lockup sem fotografia.
