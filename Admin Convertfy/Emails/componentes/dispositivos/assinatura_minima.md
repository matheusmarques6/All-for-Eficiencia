# O que é

Fecha a peça como assinatura, reduzindo navegação e estímulos concorrentes. Move o leitor para uma saída simples quando a mensagem já cumpriu seu trabalho.

# Quando usar

Use no fim de peças editoriais ou focadas, quando um menu amplo diluiria a ação principal.

# Quando não usar

Não use quando o leitor precisa escolher destinos; use `menu_de_saida`.
