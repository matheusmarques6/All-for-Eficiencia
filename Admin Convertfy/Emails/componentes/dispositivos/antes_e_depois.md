# O que é

Demonstra transformação colocando dois estados comparáveis lado a lado. Move a decisão pela evidência visual do resultado, não por uma alegação adicional.

# Quando usar

Use depois da promessa quando o resultado é fotografável e os dois registros são equivalentes.

# Quando não usar

Não use para comparar marca e concorrência; use `comparacao_pareada`. Sem equivalência visual, use `prova_por_relato`.
