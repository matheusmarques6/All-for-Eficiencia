# O que é

Organiza descoberta por ocasião de uso, não por atributo ou ranking de produto. Move o leitor a se reconhecer numa situação e então navegar para o conjunto relevante.

# Quando usar

Use no meio da peça quando o catálogo precisa ser traduzido em contextos de escolha.

# Quando não usar

Não use para produtos equivalentes lado a lado; use `vitrine_paralela`. Se cada produto precisar de frase própria, use `vitrine_narrada`.
