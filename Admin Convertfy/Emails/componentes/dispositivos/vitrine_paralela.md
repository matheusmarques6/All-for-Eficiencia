# O que é

Coloca produtos equivalentes lado a lado, cada um com destino próprio e sem descrição extensa. Move a decisão por comparação rápida e amplitude de escolha.

# Quando usar

Use para dois, quatro ou nove itens que podem ser avaliados pelo mesmo conjunto de informações.

# Quando não usar

Não use quando cada item precisa de argumento próprio; use `vitrine_narrada`. Para vários ângulos do mesmo item, use `galeria_de_angulos`.
