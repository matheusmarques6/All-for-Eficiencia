# O que é

Compara duas alternativas usando os mesmos critérios linha a linha. Move a decisão tornando diferenças verificáveis e reduzindo o custo mental de avaliar opções.

# Quando usar

Use no meio ou fim da peça quando a objeção é por que escolher esta solução em vez da alternativa.

# Quando não usar

Não use para transformação temporal; use `antes_e_depois`. Sem critérios equivalentes, use `tese_declarada` ou `lista_enumerada`.
