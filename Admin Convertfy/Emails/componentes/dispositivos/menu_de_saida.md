# O que é

Oferece destinos de navegação no fim da mensagem. Move a decisão residual dando caminhos úteis a quem não seguiu o CTA principal.

# Quando usar

Use no rodapé quando categorias, suporte ou conta ainda são saídas relevantes.

# Quando não usar

Não use quando a peça pede encerramento silencioso; use `assinatura_minima`.
