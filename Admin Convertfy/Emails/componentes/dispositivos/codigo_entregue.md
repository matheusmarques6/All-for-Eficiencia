# O que é

Entrega um código novo em texto real e cumpre a promessa que trouxe o leitor até a mensagem. Move a decisão removendo a incerteza sobre qual benefício foi concedido e como ativá-lo.

# Quando usar

Use no primeiro toque em que um opt-in ou promessa comercial exige a entrega literal do código.

# Quando não usar

Não use para repetir código já visto; use `codigo_relembrado`. Se a oferta não depende de código, use `oferta_em_manchete` ou `oferta_condicionada`.
