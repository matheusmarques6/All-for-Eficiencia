# O que é

Apresenta o conjunto como argumento e leva o leitor à coleção, não a um item isolado. Move a decisão pela amplitude e coerência do lançamento ou seleção.

# Quando usar

Use na abertura ou vitrine quando o destino correto é uma coleção completa.

# Quando não usar

Não use para itens equivalentes com destinos separados; use `vitrine_paralela`.
