# O que é

Combina prova social e exposição de produtos no mesmo bloco. Move a decisão ao ligar a experiência relatada a itens concretos que podem ser escolhidos.

# Quando usar

Use quando cada prova pode ser associada a produto ou variante específica.

# Quando não usar

Não use se a grade de produtos já domina a peça; use `prova_por_volume` ou `prova_por_relato` para evitar duplicação.
