# O que é

Decompõe um argumento em três a cinco itens com título próprio. Move a decisão ao transformar uma promessa ampla em partes escaneáveis e comparáveis.

# Quando usar

Use no corpo quando etapas, benefícios ou diferenciais precisam ser percorridos como conjunto.

# Quando não usar

Não use para apontar a própria foto; use `mecanismo_apontado`. Para uma única afirmação, use `tese_declarada`.
