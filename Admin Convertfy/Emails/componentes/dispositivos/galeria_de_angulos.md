# O que é

Mostra o mesmo produto por vários ângulos para reduzir incerteza visual. Move a decisão dando inspeção suficiente antes do clique.

# Quando usar

Use quando forma, acabamento ou construção não cabem numa única foto.

# Quando não usar

Não use para comparar produtos diferentes; use `vitrine_paralela` ou `vitrine_narrada`.
