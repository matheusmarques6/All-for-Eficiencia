# O que é

Mostra várias avaliações curtas ou uma nota agregada para demonstrar consenso. Move a decisão pela repetição e pelo tamanho da base de prova.

# Quando usar

Use quando há quantidade real de avaliações e relatos distintos suficientes.

# Quando não usar

Não use para um único caso detalhado; use `prova_por_relato`. Sem volume verificável, não fabrique o número.
