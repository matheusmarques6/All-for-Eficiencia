# O que é

Explica um único produto antes de apresentar preço ou CTA. Move a decisão aumentando compreensão e valor percebido do item protagonista.

# Quando usar

Use quando um produto merece foco e possui atributos concretos suficientes para sustentar o bloco.

# Quando não usar

Não use para comparar vários itens; use `vitrine_paralela` ou `vitrine_narrada`.
