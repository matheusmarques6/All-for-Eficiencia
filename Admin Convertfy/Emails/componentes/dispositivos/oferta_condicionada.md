# O que é

Faz da regra do incentivo o próprio conteúdo: combinação, brinde, frete, duas ofertas ou valor fixo. Move a decisão esclarecendo o que precisa acontecer para o benefício existir.

# Quando usar

Use quando a condição muda a compreensão ou a elegibilidade da oferta.

# Quando não usar

Não use para simples entrega de código; use `codigo_entregue`. Se o código vem depois de manifesto ou prova, use `oferta_adiada`.
