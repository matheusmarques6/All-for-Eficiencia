# O que é

Faz da disponibilidade real o argumento do bloco. Move a decisão ao mostrar o que ainda pode ser escolhido, sem fabricar urgência de tempo.

# Quando usar

Use quando o estoque e os estados disponível/esgotado chegam de integração confiável.

# Quando não usar

Não use com dados manuais ou desatualizados; use `prazo_declarado` quando a limitação real for temporal.
