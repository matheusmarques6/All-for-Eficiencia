# O que é

Liga cada alegação a um ponto visível da própria imagem por marcadores ou chamadas. Move a decisão mostrando onde o diferencial existe, em vez de apenas afirmá-lo.

# Quando usar

Use quando partes, ingredientes ou componentes podem ser localizados na fotografia.

# Quando não usar

Não use para benefícios abstratos; use `lista_enumerada`. Para vários ângulos do mesmo item, use `galeria_de_angulos`.
