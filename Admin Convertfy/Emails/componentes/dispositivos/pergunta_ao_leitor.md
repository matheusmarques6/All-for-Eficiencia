# O que é

Abre com uma pergunta dirigida que força comparação ou autoavaliação. Move a decisão fazendo o leitor formular mentalmente o problema antes de receber a resposta.

# Quando usar

Use no topo quando a pergunta é específica, relevante e respondida pela sequência.

# Quando não usar

Não use como pergunta retórica sem consequência; use `tese_declarada` para afirmar diretamente.
