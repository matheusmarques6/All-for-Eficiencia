# O que é

Nomeia uma dúvida que o leitor provavelmente terá e a resolve em formato explícito de pergunta e resposta. Move a decisão reduzindo incerteza antes que ela vire abandono.

# Quando usar

Use no corpo quando perguntas recorrentes bloqueiam a próxima ação.

# Quando não usar

Não use para listar benefícios; use `lista_enumerada`. Para declarar uma posição sem pergunta, use `tese_declarada`.

# O que ele exige

- Nenhum requisito cadastrado específico; as alegações ainda precisam ser verificáveis.

# Variantes que realizam

Nenhuma variante ativa realiza este dispositivo hoje.

# Lacuna

- Não há variante ativa para este dispositivo; `body-7-faq` está inativa. A biblioteca possui uma lacuna operacional.
