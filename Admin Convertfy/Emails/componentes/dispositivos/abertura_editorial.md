# O que é

Abre a peça com imagem e uma ideia, sem transformar oferta, código ou prazo no argumento. Move o leitor da chegada para o interesse pelo assunto antes da decisão comercial.

# Quando usar

Use no início quando contexto, história ou coleção precisam preparar a leitura.

# Quando não usar

Não use para cumprir promessa de incentivo; nesse caso use `codigo_entregue`, ou `oferta_em_manchete` quando o desconto for o argumento.

- [[terco-superior-liso]]
