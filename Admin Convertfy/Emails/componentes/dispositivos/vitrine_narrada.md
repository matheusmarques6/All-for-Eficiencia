# O que é

Mostra poucos produtos e dá a cada um uma frase própria. Move a decisão ajudando o leitor a entender diferenças e escolher pelo significado, não apenas pela imagem.

# Quando usar

Use quando cada item precisa de contexto curto e destino próprio.

# Quando não usar

Não use para catálogo amplo sem descrição; use `vitrine_paralela`. Para um único item, use `produto_unico_aprofundado`.
