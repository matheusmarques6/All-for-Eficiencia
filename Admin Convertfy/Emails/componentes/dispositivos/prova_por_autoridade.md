# O que é

Usa cargo, experiência ou credencial verificável como razão para confiar no depoimento. Move a decisão pela competência reconhecida da fonte.

# Quando usar

Use quando a identidade e a qualificação do depoente são relevantes ao argumento.

# Quando não usar

Não use quando o valor está na história vivida; use `prova_por_relato`. Para efeito de maioria, use `prova_por_volume`.
