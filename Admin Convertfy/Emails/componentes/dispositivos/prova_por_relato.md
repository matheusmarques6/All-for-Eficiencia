# O que é

Sustenta a confiança com um relato longo, específico e verificável. Move a decisão pela concretude da experiência individual, não pelo número de avaliações.

# Quando usar

Use no meio ou fim quando um caso detalhado responde melhor à objeção do que várias frases curtas.

# Quando não usar

Não use para mostrar consenso; use `prova_por_volume`. Se a credencial da pessoa for o argumento, use `prova_por_autoridade`.
