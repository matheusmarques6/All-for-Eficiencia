# O que é

Usa o nome reconhecível de um evento ou campanha como moldura da oferta. Move a decisão por contexto compartilhado: o leitor entende imediatamente por que a comunicação existe.

# Quando usar

Use na abertura de campanhas cujo nome organiza expectativa, linguagem e timing.

# Quando não usar

Não use quando o evento é irrelevante ou não existe; use `oferta_em_manchete` se apenas o incentivo importa.
