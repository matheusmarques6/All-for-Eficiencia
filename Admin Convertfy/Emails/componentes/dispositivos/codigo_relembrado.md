# O que é

Repete um código que o leitor já recebeu e pressupõe memória ou toque anterior. Move a decisão reativando um benefício conhecido, sem apresentar uma nova concessão.

# Quando usar

Use em recuperação ou continuidade depois da entrega original do incentivo.

# Quando não usar

Não use no primeiro toque; use `codigo_entregue` para cumprir a promessa inicial.

# O que ele exige

- [[cupom-ativo]]
