# O que é

Transforma uma situação vivida no argumento principal do bloco. Move a decisão por identificação com a cena, não pela enumeração de atributos do produto.

# Quando usar

Use no corpo quando o leitor precisa imaginar o produto dentro de uma situação concreta.

# Quando não usar

Não use quando a prova é uma transformação mensurável; use `antes_e_depois`. Para explicar partes visíveis, use `mecanismo_apontado`.
