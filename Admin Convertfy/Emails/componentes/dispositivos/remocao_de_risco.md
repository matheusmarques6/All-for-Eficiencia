# O que é

Transforma garantias e proteções operacionais no conteúdo principal do bloco. Move a decisão reduzindo o custo percebido de errar, testar ou comprar.

# Quando usar

Use perto do fechamento quando troca, garantia, entrega ou suporte são a objeção restante.

# Quando não usar

Não use para prova social; use um dispositivo de `prova_*`. Não prometa proteção que a operação não sustenta.
