# O que é

Faz a peça parecer outro formato reconhecível para romper a leitura automática. Move a decisão pelo estranhamento e pelo código cultural antes do argumento literal.

# Quando usar

Use na abertura quando o formato emprestado é compreensível pelo público e coerente com a voz.

# Quando não usar

Não use como ornamento genérico; use `abertura_editorial` quando a imagem e a frase bastam.
