# A restrição

Tipografia monoespaçada é, por construção, um registro dominante — cada
caractere ocupa a mesma largura, o que chama atenção para si mesmo. Ao
lado de uma identidade que já usa serif ou script display forte, os
dois registros disputam o mesmo protagonismo visual em vez de dividir
papéis.

# Onde o inventário declara

- `review 3`: *"Marca com tipografia serifada ou display de identidade forte — o monoespaçado é dominante demais para conviver."*

# Como o agente aplica

Passo 8 do [[_protocolo-de-selecao]]. Variantes que usam fonte
monoespaçada como elemento de identidade ficam indisponíveis para peças
cuja marca já declara o requisito [[../requisitos/serif-ou-script-display]]
em alguma outra seção da mesma peça — e vice-versa.
