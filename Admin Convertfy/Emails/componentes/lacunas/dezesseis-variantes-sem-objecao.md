# O que falta

16 das 44 variantes têm `objecao: []` no frontmatter. Metade tem
explicação já registrada em outro lugar: os 4 footers (correto por
desenho — footer fecha o e-mail, não ataca objeção; ver o comentário
padrão `# footer não ataca objeção; o ranking degrada para registro (§6.1)`
nas quatro notas) e as 4 variantes sem julgamento nenhum
([[body-quatro-variantes-sem-julgamento]]). As outras 8 não têm explicação
registrada: [[body-2-colagem-de-data-comemorativa]],
[[body-3-pitch-de-gift-card]], [[offer-1-condicao-sem-imagem]],
[[offer-2-duas-ofertas-sazonais]], [[offer-3-lembrete-de-cupom]],
[[offer-6-carrinho-preto-e-branco]], [[products-3-arco-de-novidades]] e
[[products-6-vitrine-de-sale]].

Uma delas já traz uma pista gravada no próprio frontmatter: `body-2` tem o
comentário `# "argumento é a cena, não o preço nem a especificação" --
nenhum valor do vocabulario de objecao descreve gatilho emocional/afeto de
presente`. As outras sete não têm anotação nenhuma explicando o vazio.

# Por que importa

`objecao` é o primeiro eixo de ranking do [[_protocolo-de-selecao|protocolo
de seleção]], depois dos filtros de `momento`. Uma variante com
`objecao: []` não é eliminada — ela degrada para o próximo eixo
(`registro`), do mesmo jeito que os footers fazem por desenho. Para as 8
sem explicação, não dá para saber se `objecao: []` é uma propriedade real
da variante (ela genuinamente não ataca nenhuma objeção do vocabulário,
como o caso de `body-2`) ou uma lacuna de classificação (a variante ataca
uma objeção real, mas ninguém a classificou ainda). São dois cenários com
consequência prática diferente: no primeiro, degradar para `registro` é
correto; no segundo, o ranking está perdendo um sinal que deveria existir.

# O que se perde hoje

Sem essa distinção registrada, cada uma das 8 fica ambígua: quem for
expandir o vocabulário de objeção (por exemplo, ao corrigir
[[conceitos-sem-requisito]], que já aponta a falta de um valor para
"gatilho emocional/afeto de presente") não sabe, olhando só o frontmatter,
quais das 8 são candidatas a ganhar `objecao` preenchido e quais devem
continuar vazias por desenho.

# Fora do escopo desta entrega

Reler a prosa das 7 variantes sem anotação e decidir, uma a uma, se
`objecao: []` é propriedade real ou lacuna de classificação — julgamento de
conteúdo que caberia à mesma revisão que já anotou o caso de `body-2`.
Registrado aqui para a pergunta não se perder.
