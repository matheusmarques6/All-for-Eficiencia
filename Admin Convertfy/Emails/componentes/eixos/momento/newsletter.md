# Newsletter

Envio editorial de cadência regular — não amarrado a evento comportamental
nem a oferta pontual. Mistura conteúdo, atualização de marca e,
eventualmente, produto, mas o contrato com o assinante é "recebo isso
periodicamente", não "isso responde a algo que eu fiz".

# Como usar na seleção

Uma variante com `momento: [newsletter]` não deve depender de gatilho
comportamental (carrinho, navegação) para fazer sentido — precisa ser
autossuficiente para qualquer assinante ativo no dia do envio. Aceita mistura
de seções (produto, conteúdo, comunidade) que uma peça de conversão pontual
concentraria em um só argumento.
