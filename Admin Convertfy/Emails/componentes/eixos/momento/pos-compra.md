# Pós-compra

A pessoa já comprou. O trabalho muda de convencer para reter, ensinar ou
expandir: confirmar a decisão (reduzir arrependimento), garantir que ela saiba
usar o produto, e abrir caminho para a próxima compra sem parecer que a marca
só queria a venda.

# Onde aparece na doutrina

As restrições cross-flow de
[[cada-alegacao-e-uma-promessa-operacional]] e
[[remocao-de-risco-escala-com-o-ticket]] se aplicam também a este flow.

# Como usar na seleção

Uma variante com `momento: [pos-compra]` costuma casar com as objeções
`uso-aprendizado` (ensinar a usar) ou `suporte-duvida` (garantir que existe
ajuda). Cross-sell entra só depois desse trabalho de retenção — puxar
catálogo cedo demais neste momento lê como a marca só querendo a próxima
venda.
