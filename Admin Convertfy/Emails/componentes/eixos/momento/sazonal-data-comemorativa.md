# Sazonal / data comemorativa

Disparo amarrado a uma data específica do calendário — feriado, Black
Friday, dia das mães, aniversário da marca. Diferente de `campanha-promocional`
genérica, o gancho temático da data é parte do argumento, não só o pretexto
para o desconto: a peça precisa se sustentar como relevante àquela data, não
só como oferta com prazo qualquer.

# Como usar na seleção

Uma variante com `momento: [sazonal-data-comemorativa]` costuma usar
`paleta: festivo` e visual temático. Cuidado ao reaproveitar fora da janela
real da data — o mesmo mecanismo de "prazo decorativo" que queima confiança
em urgência (ver [[deadline-falso-queima-o-proximo]]) se aplica a datas: se a
promoção "de Black Friday" ainda roda em dezembro, o gancho vira mentira.
