# Nutrição de conteúdo

E-mail sem pedido comercial direto — educa, entretém ou aprofunda a relação
com a marca sem pedir clique de compra como objetivo principal. Existe para
manter a lista quente entre momentos comerciais, não para fechar venda nesta
peça.

# Como usar na seleção

Uma variante com `momento: [nutricao-de-conteudo]` pode não ter CTA de
compra dominante — ver [[um-cta-dominante-em-email-curto]] para quando ele
existir, mas aqui o CTA pode ser de leitura, não de carrinho. Não force uma
variante pensada para converter (`campanha-promocional`, `sale-recorrente`)
neste momento: o objetivo da peça é diferente, e o julgamento de sucesso
também.
