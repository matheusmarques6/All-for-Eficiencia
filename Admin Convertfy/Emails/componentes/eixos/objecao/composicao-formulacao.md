# Composição e formulação

"Como isso é feito? Como isso se sustenta?" É a objeção do cético — quem já
ignorou a tese e a pressão e só compra convencido. Não basta alegar
qualidade; é preciso mostrar o mecanismo: de que é feito, o que foi cortado
ou realocado para o preço competir, o que é verificável em cada pedido.

# Onde aparece na doutrina

Intenção do terceiro toque do welcome: [[welcome-3]], que a tabela de [[_flow]] nomeia
"como isso se sustenta? (o cético)" e descreve como três porquês encadeados:
origem, economia, operação.

# Como usar na seleção

Uma variante declara `objecao: [composicao-formulacao]` quando o dispositivo
dela expõe o COMO — ingrediente, processo, origem, engenharia — não apenas o
QUE (isso é `qualidade-eficacia`) nem o QUANTO CUSTA (isso é `preco-valor`).
Cada detalhe de mecanismo citado é uma promessa operacional: ver
[[cada-alegacao-e-uma-promessa-operacional]].

# Cuidado de posição

E-mail de mecanismo tende a ser o mais longo do flow por decisão — mas ainda
precisa de saída rápida para quem já amadureceu a decisão antes de chegar ao
fim. Ver [[saida-rapida-no-primeiro-terco]].
