# Pertencimento

"Essa marca é para gente como eu?" Diferente de `adesao-social` — que
responde "estou sozinha decidindo?" com volume de gente decidindo — esta
objeção é sobre identidade, não sobre quantidade: a pessoa precisa se
reconhecer no público da marca antes de se sentir à vontade para comprar
dela.

# Como usar na seleção

Uma variante declara `objecao: [pertencimento]` quando o dispositivo dela
comunica quem é o público da marca de um jeito que convida identificação —
estética, linguagem, causa, comunidade — não quando apenas mostra volume de
compradores (isso permanece `adesao-social`). O registro `comunidade-identitario`
é o veículo típico, mas os dois eixos respondem perguntas diferentes: um é de
estilo, o outro é de objeção.
