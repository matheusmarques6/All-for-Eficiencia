# Comunidade identitário

Registro que fala para um grupo, não para um indivíduo isolado — usa
linguagem de pertencimento ("a gente", "nossa comunidade"), referência
cultural específica do público, e prova social que é sobre identidade
compartilhada, não sobre volume genérico.

# Como usar na seleção

É o veículo típico da objeção `pertencimento`, mas os dois eixos não são o
mesmo: um valor de `registro` descreve como a peça soa; o valor de `objecao`
descreve qual dúvida ela resolve. Uma peça pode usar este registro sem
resolver `pertencimento` diretamente, se o argumento principal for outro.
