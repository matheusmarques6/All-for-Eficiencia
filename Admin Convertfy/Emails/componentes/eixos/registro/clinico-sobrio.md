# Clínico sobrio

Registro de precisão técnica: linguagem factual, dado concreto em vez de
adjetivo, ausência de apelo emocional explícito. Comunica confiabilidade pela
exatidão, não pelo entusiasmo — o oposto de `volume-impulso` e de `festivo`.

# Como usar na seleção

É o registro natural para a objeção `composicao-formulacao` — mecanismo,
ingrediente, dado técnico pedem esse tom para soar crível, não vendedor
demais. Categorias regulamentadas ou de alto risco percebido (saúde, finanças,
segurança infantil) tendem a exigir este registro independente do momento.
