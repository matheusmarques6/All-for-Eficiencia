# Festivo

Registro temático de celebração: cor e motivo gráfico amarrados a uma data
ou ocasião, tom de comemoração em vez de venda direta. Existe para sinalizar
"isto é sobre a data", não apenas "isto é uma oferta com um enfeite".

# Como usar na seleção

É o registro natural de `momento: sazonal-data-comemorativa`. Fora dessa
janela de tempo, o registro perde sentido e pode até prejudicar — motivo
gráfico de Black Friday em fevereiro lê como erro de produção, não como
estilo.
