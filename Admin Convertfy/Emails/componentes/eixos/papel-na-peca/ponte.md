# Ponte

Bloco de transição — existe para conectar dois blocos de natureza diferente
sem quebra abrupta de tom ou assunto, não para carregar argumento próprio.
Costuma ser curto: uma frase de virada, um subtítulo, um pequeno resumo antes
de mudar de registro (por exemplo, de argumento de marca para prova social).

# Como usar na seleção

Uma variante com `papel-na-peca: [ponte]` deve ser objetivamente mais curta
que os blocos que conecta — se a ponte compete em tamanho com o `meio` ao
redor, ela deixou de ser transição e virou conteúdo, e o papel declarado está
errado.
