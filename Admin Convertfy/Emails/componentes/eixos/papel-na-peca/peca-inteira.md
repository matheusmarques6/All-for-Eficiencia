# Peça inteira

O dispositivo ocupa o e-mail inteiro — não é um bloco entre outros, é a
estrutura completa. Típico de e-mails que quebram deliberadamente o padrão de
seções (abre/meio/fecha) porque o mecanismo só funciona como unidade única:
uma carta em plain-text, um e-mail-pergunta de uma linha.

# Onde aparece na doutrina

O epílogo do welcome é o exemplo canônico: texto corrido, sem blocos
segmentados, assinatura de equipe — ver [[8]] e
[[quebra-de-formato-atravessa-a-cegueira]]. A quebra de formato é o próprio
mecanismo, não decoração.

# Como usar na seleção

Uma variante com `papel-na-peca: [peca-inteira]` não compõe com outras
variantes na mesma peça — ao ser selecionada, ela É o e-mail, substituindo a
composição normal de seções. Reservar para momentos que pedem exatamente essa
quebra (tipicamente `welcome-tardio` no epílogo, ou reengajamento com tom
pessoal), nunca como padrão default.
