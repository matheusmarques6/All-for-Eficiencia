# Com acento definido

Base neutra (branco, cinza ou creme) com uma cor de acento única e
consistente, reservada para elementos que pedem atenção — CTA, título,
selo. A cor de acento não se espalha pela peça inteira; ela marca o que
importa.

# Como usar na seleção

É a paleta mais fácil de garantir CTA dominante e visível — ver
[[um-cta-dominante-em-email-curto]] — porque a cor de acento só aparece onde
a hierarquia pede. Boa escolha default quando a marca tem uma cor
institucional forte mas o momento não pede a intensidade de
`escuro-saturado` nem a neutralidade total de `cinza-neutro`.
