# Observação

Em [[avelmore-mecanismo-e-origem]], quem já decidiu não tem por onde entrar. O
primeiro CTA é *"read the full story"*; o primeiro CTA de compra só aparece
depois de ~7 parágrafos.

O e-mail é para o cético — mas alguém pode ter amadurecido entre o #2 e o #3 e
chegar pronto para comprar.

# Regra derivada

E-mail de profundidade ainda precisa de saída rápida de compra no primeiro terço.
Escolher um leitor não é o mesmo que trancar a porta para os outros.
