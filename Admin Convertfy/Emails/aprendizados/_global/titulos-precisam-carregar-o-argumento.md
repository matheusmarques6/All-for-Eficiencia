# Observação

A varredura de [[avelmore-deadline-objecao]] funciona porque respeita como e-mail
é lido: uma fração pequena das palavras, em saltos.

# Regra derivada

**Teste de escaneabilidade:** se os títulos sozinhos não contam a história, o
bloco falhou.

Vale para qualquer bloco de lista, em qualquer flow. O corpo do item é para quem
parou; o título é para quem não parou — e quem não parou é a maioria.

Corolário: itens de uma varredura precisam ter **naturezas distintas**. Cinco
variações de "qualidade" não são varredura, são repetição.
