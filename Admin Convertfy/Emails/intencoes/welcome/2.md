# O que este e-mail deve fazer

Estado mental: já recebeu o welcome #1 e não comprou. Tem o código, conhece a
tese, e mesmo assim não avançou. Não é falta de informação — é falta de decisão.

O trabalho: converter um cupom aberto em compra hoje. O #1 podia se dar ao luxo
de construir marca; este não pode. É o e-mail que fecha a janela.

# Os dois mecanismos

**Deadline.** Uma hora explícita é a mudança mais importante do e-mail. O #1
dizia "por tempo limitado" — vago, adiável. Aqui existe uma hora. Isso transforma
um cupom que dorme na caixa de entrada em uma decisão com custo de adiar.

**Objeção exaustiva.** Em vez de uma tese elegante, várias razões cobrindo travas
diferentes. O #1 apostava numa objeção só. Este não sabe qual travou aquela
pessoa, então cobre todas.

Parte dessas razões não é benefício, é remoção de risco — frete e devolução
movidos para dentro do argumento, com detalhe operacional. No #1 isso era uma
faixa de ícones com três palavras. Aqui vira compromisso descrito.

# O que precisa ser verdade quando ele terminar de ler

- A objeção específica dela foi endereçada.
- Existe uma hora limite.
- Ela sabe o preço e viu opções.

# O que este e-mail NÃO deve fazer

- Não repete a história da marca.
- Não pede prova social — já não é sobre confiar, é sobre decidir.
- Não introduz desconto novo nem aumenta o existente.
