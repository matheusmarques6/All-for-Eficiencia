# A intenção do flow inteiro

O welcome nasce de um contrato: a pessoa entregou o e-mail em troca de uma
promessa (quase sempre um incentivo). Ela chega no pico de atenção que nunca mais
vai se repetir — e a atenção só decai daí em diante. O flow inteiro é desenhado
sobre essa curva.

**O flow é uma varredura de objeções, não uma repetição de oferta.** Cada toque
assume que o anterior falhou e ataca uma objeção de natureza diferente, num
registro diferente. Quem não comprou depois do toque N não precisa ouvir o
argumento N de novo — precisa de um argumento de outro tipo. O eixo:

| Toque | Objeção que ataca |
|---|---|
| [[1\|1]] | "esse produto presta?" |
| [[2\|2]] | "vale o que custa?" (varredura — não se sabe qual travou) |
| [[3\|3]] | "como isso se sustenta?" (o cético) |
| [[4\|4]] | "sou só eu que estou considerando?" |
| [[5\|5]] | "por que comprar de VOCÊS?" (o canal) |
| [[6\|6]] | "por que agora?" |
| [[7\|7]] | "ainda dá tempo?" |
| [[8\|8]] | "perdi?" |

**A voz rotaciona** para o mesmo argumento nunca chegar duas vezes do mesmo
lugar: marca → marca → marca → clientes → marca contra a categoria → números →
relógio → uma pessoa.

**A leitura pedida decresce; a decisão pedida cresce.** O primeiro toque pode
pedir minutos; o penúltimo pede segundos. Quanto mais fundo no flow, menos
argumento e mais gatilho.

# Regras do incentivo (transversais, invioláveis)

1. O incentivo prometido é entregue no toque 1, inteiro e sem fricção.
2. O valor do incentivo nunca aumenta ao longo do flow — insistir não pode pagar.
3. Prazo de hora fechada existe UMA vez, no fechamento do ciclo da oferta —
   toques intermediários usam no máximo "por tempo limitado".
4. Tudo que vem depois do prazo honra a expiração. A credibilidade do prazo não
   se decide no e-mail que o anuncia; se decide no e-mail seguinte.
5. Extensão é permitida só como exceção declarada: explícita (admite que o prazo
   venceu), justificada (tem motivo com dono), única (uma por flow) e final (vem
   com linguagem de definitividade). Assim ela fortalece o prazo em vez de
   destruí-lo.
6. O flow termina. Ele não vira campanha permanente.

# O que é da loja (e portanto NÃO está nestas notas)

Qual é a tese, quais objeções específicas da categoria, qual história, quais
medos do canal, quais números. A intenção diz o que precisa acontecer; a loja e
as referências decidem como.
