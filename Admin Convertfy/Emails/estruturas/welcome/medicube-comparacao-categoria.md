Serve a intenção [[5|welcome 5]].

A estrutura mais curta do lote: um único bloco argumentativo entre header e
vitrine.

# O dispositivo

Bloco escuro inteiro. Headline *"We're not your average Korean skincare store"*.
Coluna central Medicube com **4 checks**, cercada por 2 colunas *"Other stores"*
com **8 X's**.

| Medicube (4) | Other stores (8) |
|---|---|
| Promoções generosas | Qualidade desconhecida |
| Variedade | Falsificação |
| Serviço personalizado | Atendimento não confiável |
| Experiência estabelecida | Sem garantia de devolução |
| | Entrega demorada |
| | Custo escondido |
| | Site duvidoso |
| | Pagamento inseguro |

# A estrutura

| # | Seção | Composição | Papel |
|---|---|---|---|
| 1 | `header` | Logo Medicube + tagline *"K-BEAUTY TECH"* | Ancorar. A tagline já é posicionamento — categoria + diferencial em três palavras. |
| 2 | `body` (comparação) | Bloco escuro: headline + comparação 4×8 + cupom WELCOME10 + *"ENJOY DISCOUNT"* — um bloco só | O e-mail inteiro. Nomear os medos da categoria, riscar todos, ficar sozinho no centro — e fechar com o código. O cupom dentro do bloco segue a gramática do flow: fecha o argumento, não interrompe. |
| 3 | `products` | Grade 2×2 com rating, preço e botão + *"GET 10% OFF"* | Aterrissar. Mantém a oferta viva no clique. |
| 4 | `footer` | Logo, 4 categorias, copyright, suporte | Saída. |

**Fio narrativo:** você conhece os riscos de comprar isso online → nós somos a
exceção, ponto a ponto → o código segue seu → escolhe.

# O que varia por loja

Quais medos da categoria entram nos X's. Falsificação e pagamento inseguro são de
K-beauty. Numa loja de ferramenta seriam peça genérica e suporte inexistente; num
e-commerce BR, frete que não chega e site golpe.

# Quando usar

Toque tardio de flow, quando a dúvida competitiva já amadureceu e os registros
anteriores (tese, urgência, mecanismo, prova) já foram gastos.

# Quando NÃO usar

Toque inicial. Ver [[posicao-muda-o-efeito-do-dispositivo]] — este dispositivo
cedo demais planta a dúvida que pretendia curar.
